Hardening Target

  • SSH tidak memakai port default 22
  • SSH dipindahkan ke port 2222
  • Root login dimatikan
  • Password login dimatikan setelah SSH key siap
  • Firewall hanya membuka port yang dibutuhkan

Kali Linux Command Checklist

sudo nano /etc/ssh/sshd_config
Port 2222
PermitRootLogin no
PasswordAuthentication no
sudo systemctl restart ssh
sudo ufw deny 22/tcp
sudo ufw allow 2222/tcp

Demo Explanation

Jika Analyzer mendeteksi port 22, status server dianggap belum aman. Jika Analyzer mendeteksi port 2222 dan port 22 tidak muncul, maka remote access sudah lebih aman.
